#string #高速化
### 概要
C++の文字列の先頭に文字を追加したいとき
``` cpp
string S;

//aを先頭に10文字追加する
S='a'+S;
cout<<S
```
のようにすると計算のたびに文字列Sを後ろにずらす再確保が発生するので$O(\vert{}S\vert{})$ の時間がかかるので、TLEする可能性が高くなる。

### 解決策

stringのコンストラクタ(初期化機能)を使って一括で追加する。

``` cpp
string(個数,'文字');

string s1(5, 'a');   // "aaaaa" という文字列が作られる
string s2(3, 'x');   // "xxx" という文字列が作られる
string s3(0, 'a');   // "" (空文字列) が作られる

//aを先頭に10文字追加する
S=string(10,'a')+S;
cout<<S
```
