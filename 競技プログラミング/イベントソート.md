#アルゴリズム #テクニック 
## 概要
主に配列の区間更新についての操作を分解して、操作の位置や時間でソートを行い、その順番で実行するアルゴリズム。

## 例

1.集合を要素として持つ配列の区間\[L,R)について、整数Xを追加する。
2.1.を規定された回数繰り返して、それぞれの要素のsizeを順番に出力する。

## 解法

1の操作について考えると、区間を０から走査していったときに、
+ 地点Lに到達した時からXを追加し続ける。
+ 地点R+1に到達した時にXを追加するのを止める。
という2つの操作に分解することができる。
操作を保存する配列eventを作り、
それぞれの動作を(L,X,1),(R,X,-1)としてeventに保存する。
(3つ目の要素はxの個数をcount用の配列で管理するために存在する。)

全ての操作をeventに追加し終えたあと、sortを行う。
ある地点Dを０から、地点Dでのイベントを全て処理するごとにDを一つずつ増やしていき、答えを出力していく。

## コード例
```cpp
#include <bits/stdc++.h>
//#include <atcoder/all>
using namespace std;
//using namespace atcoder;
#define rep(i, n) for (int i = 0; i < (int)(n); i++

template<typename T> using vc = vector<T>;
template<typename T> using vv = vc<vc<T>>;
  
int main()
{
    int N,Q;
    cin>>N>>Q;
    vc<tuple<int,int,int>> G;

    rep(i,Q)
    {
        int L,R,X;
        cin>>L>>R>>X;
        L--;
        G.push_back({L,X,1});
        G.push_back({R,X,-1});
    }
    G.push_back(N,0,0);
    sort(G.begin(),G.end());
    int now=0;
    int ans=0;
    vc<int> count(Q+1);
    for(auto &[t,x,v]:G)
    {
        while (t!=now)
        {
            now++;
            cout<<ans<<" ";
        }
        if(count[x]==0){ans++;}
        count[x]+=v;
        if(count[x]==0){ans--;}
    }
    return 0;

}

```
