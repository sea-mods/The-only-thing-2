#アルゴリズム
### 概要
DFSは(depth-first search,)の略、日本語で深さ優先探索と呼ばれる。
指定された点から離れた点に向かって一つずつ探索を行い、先に進めなくなったら一つ戻るを繰り返すアルゴリズム。
### 使用法
グラフの連結判定や迷路探索などに用いることができる

### 仕組み
隣接リスト表現されているグラフG
すでに訪れた地点を管理するためのリストseen
次に訪れる場所を管理するスタックtodoのデータがあるときを考える。

1.現在地点の番号(vとする)に対応するseenをTrueにする。
2.現在地点に隣接する地点の番号(G\[v])を全てtodoに追加する。
3.todoから頂点を取りだす。
4.todoから取り出した頂点のseenをTrueにする。
	5..todoから取り出した頂点に隣接する頂点についてseen=Trueであれば何もしない。
	6.seen=Falseの場合todoにその頂点を追加する。	
7.todoの中身がなくなるまで3~6を繰り返す
todoをキューにすると幅優先探索になる。
### 実装例

```c++
vector<bool> seen;
vector<vector<int>> G;

void dfs(vector<vrctor<int>> &G,int v)
{
	seen[v]=true;
	
	for(auto next_v;G[v])
	{
		if(seen[next_v]){continue;}
		else{dfs(G,next_v);}
	}
}
```

以下、コートの説明。

seenは添え字に対応する地点に訪れたかどうかを示すboolリスト。
GはDFSを行うグラフを指す。

dfs関数内
1行目 現在地点に対してseenをTrueにする
3行目 現在地点に隣接する地点を一つずつnext_vに取り出す
5,6行目 もうすでに訪れた地点の場合、dfsをすると重複するのでスキップする。そうでない場合はその地点からもう一度同じことを繰り返す。

計算量は頂点数 N、辺数Mのグラフに対してO(N＋M)になる。

カウンター変数ptrを用意し、関数を実行した時、関数から抜けるときにインクリメントして頂点に対応するリストにいれておけば、タイムスタンプを記録することができる。

### 活用例

与えられたデータがグラフでなくても、グラフとして表現できればDFSを使うことができる。
(例)2次元グリッドで表現された迷路

- 最初の一行目は盤面のサイズ
- '.' は通路を表す
- '#' は壁を表す (壁マスには進めない)
- 's' はスタート地点
- 'g' はゴール地点
```
10 10
s.........
#########.
#.......#.
#..####.#.
##....#.#.
#####.#.#.
g.#.#.#.#.
#.#.#.#.#.
#.#.#.#.#.
#.....#...
```
スタート地点からゴール地点に辿り着けるかどうかを判定したいとき、マスに対してDFSを行いゴール地点のマスを通ったかどうかで判定できる。
