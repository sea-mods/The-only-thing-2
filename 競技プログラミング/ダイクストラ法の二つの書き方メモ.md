#アルゴリズム 
## 概要
ダイクストラ法を実装する時にグラフを隣接リスト方式で扱うか、隣接行列方式で扱うかによって書き方が変わる。

## 隣接行列方式

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll INF = 1LL<<60;
template<typename T> using vc = vector<T>;
template<typename T> using vv = vc<vc<T>>;
template<class T> using pq = priority_queue<T, vector<T>>;//大きい順
template<class T> using pq_g = priority_queue<T, vector<T>, greater<T>>;//小さい順

int main() 
{
    int N,K;
    cin>>N>>K;
    vv<ll> G(N+1,vc<ll>(N+1,INF));

	int a,b;
	cin>>a>>b;
	vc<ll> dp(N+1,INF);
	vc<bool> seen(N+1);
	dp[a]=0;
	for (int i = 1; i <= N; i++)
	{
		ll dist=INF;
		ll min_v=-1;
		for (int j = 1; j <= N; j++)
		{
			if(seen[j]){continue;}
			if(dp[j]<dist)
			{
				dist=dp[j];
				min_v=j;
			}
		}
		if(min_v==-1)
		{
			continue;
		}
		seen[min_v]=true;
		for (int j = 1; j <= N; j++)
		{
			dp[j]=min(dp[j],dp[min_v]+G[min_v][j]);
		}
		

	}
	if(dp[b]==INF){cout<<-1<<endl;}
	else{cout<<dp[b]<<endl;}
	
    return 0;
}
```

点Sにたどり着くまでの距離を記録する一次元配列をdp[S]として、
点Sの最短距離が確定しているかどうかを示す配列をseen[S]とする。
配列dpはあらかじめ限りなく大きい数で初期化しておく。

スタート地点a、ゴール地点bを指定して、dp[a]を0に初期化する。
それぞれの点iからまだ最短距離が確定していないかつ、dpが存在する(すでに通った点に道が存在する)点の中で、最も距離が短い点を選び、seen[i]をTrueにして、その点からの順路がdpよりも短い時だけ、dpにその距離を記録することを繰り返し行う。
(グラフに道が存在しない場合、dpの値が更新されることはない。)

dp[b]が道a→bの最短距離となる。

同じ隣接行列方式でグラフを扱うワーシャルフロイト法の計算量はO(N^3)だが、こちらは、O(N^2)である。
