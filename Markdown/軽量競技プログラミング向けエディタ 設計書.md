# 軽量競技プログラミング向けエディタ 設計書
Version 0.1

---

## 1. 概要

### 1.1 プロジェクト名

仮称：

**LightCP Editor**

競技プログラミングに特化した、軽量・高速なネイティブコードエディタを開発する。

### 1.2 開発目的

Visual Studio Codeなどの汎用エディタは非常に高機能である一方、競技プログラミングに不要な機能やバックグラウンドプロセスも多い。

本プロジェクトでは、

> 「競技プログラミングに必要な機能だけを高速・軽量に提供する」

ことを目的とする。

特に以下を重視する。

- 起動の速さ
- 低メモリ使用量
- 低CPU使用率
- 大きなソースコードの高速編集
- C++競技プログラミングへの最適化
- コンパイル・テスト・提出の簡略化
- ライブラリ管理
- カスタマイズ性

---

# 2. 基本方針

## 2.1 最重要原則

### 原則1：不要な機能を実装しない

一般的なIDEに存在する機能をすべて搭載するのではなく、競技プログラミングに必要な機能に限定する。

---

### 原則2：外部機能は可能な限り別プロセス

エディタ本体に機能を詰め込まない。

```text
editor.exe
    │
    ├── compiler.exe
    ├── test_runner.exe
    ├── formatter.exe
    ├── library_manager.exe
    └── submitter.exe
```

必要なときだけ起動し、処理終了後に終了させる。

これにより、

- メモリ使用量
- クラッシュの影響
- モジュール間の依存関係

を抑える。

---

### 原則3：エディタ本体は常駐機能を最小限にする

エディタ本体に常駐させるもの：

- ウィンドウ
- テキストバッファ
- 描画
- カーソル
- ファイル管理
- 編集操作
- 検索
- 最低限の構文ハイライト
- 最低限のコード補完

---

### 原則4：メモリ使用量を設計段階から管理する

「完成してから軽量化する」のではなく、最初からメモリ予算を設定する。

# 7. Text Buffer

エディタの最重要コンポーネント。

## 7.1 要件

- 大きなファイルを扱える
- 挿入・削除が高速
- Undo/Redoに適する
- 編集によるメモリ増加を抑える
- 行番号を高速に取得できる

---

## 7.2 採用候補

第一候補：

**Piece Table**

概念：

```text
Original Buffer
        │
        │
        ├──────────────┐
        │              │
        ▼              ▼
     Piece 1        Piece 2

Add Buffer
        │
        ▼
     Piece 3
```

元ファイルを直接大量コピーせず、追加データを別バッファに保存する。

---

## 7.3 基本構造

概念的には、

```cpp
enum class BufferType {
    Original,
    Add
};

struct Piece {
    BufferType buffer;
    size_t offset;
    size_t length;
};
```

とする。

実際のコンテナは編集性能を考慮して決定する。

候補：

- B-tree
- Rope
- Gap Bufferとの比較

# 10. 構文ハイライト

## 10.1 方針

完全なC++コンパイラレベルの解析は行わない。

競技プログラミング用として必要十分なトークン解析を行う。

対象：

- コメント
- キーワード
- 数値
- 文字列
- 型
- プリプロセッサ
- 関数
- 演算子

---

## 10.2 遅延解析

編集したファイル全体を毎回再解析しない。

```text
変更位置
 ↓
影響範囲を推定
 ↓
必要範囲のみ再解析
```

とする。

# 26. CPU使用量

アイドル時は、

```text

```

を目標とする。

```cpp

    update();
```

```text
OS Event
 ↓
必要な処理
 ↓
待機
```

# 38. 最終的な思想

このエディタは、

**「小さいVS Code」**

を目指すのではない。

**「競技プログラミングのために必要な機能だけを持つ、高速なネイティブエディタ」**

を目指す。

```text
             VS Code
                │
       ┌────────┴────────┐
       │                 │
   大量の機能          拡張性
       │                 │
       └────────┬────────┘
                │
          大きなシステム
                │
             高負荷


          LightCP Editor
                │
       ┌────────┴────────┐
       │                 │
   必要な機能          専用最適化
       │                 │
       └────────┬────────┘
                │
          小さなシステム
                │
            低メモリ
            高速起動
```

最終目標は、

> **「起動した瞬間に使えて、競プロに必要なことは全部できる。しかし裏ではほとんど何も動いていない」**

というエディタである。
